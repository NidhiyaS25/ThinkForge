1. EXECUTIVE PROJECT OVERVIEW
================================================================================
Modern generative AI in education creates a dangerous failure mode: student cognitive 
dependency. Students copy and paste prompts into chatbots and receive ready-made answers, 
bypassing the productive struggle required to develop deep understanding.

ThinkForge ("Don't replace thinking. Forge it.") transforms AI from an "answer vending 
machine" into a strict pedagogical coach that trains students to need AI less.

Core Tenets:
1. Attempt-First Enforcement: No AI hints can be requested until the learner commits an 
   initial, timestamped solution attempt.
2. Progressive Socratic Fading: AI guidance follows three strict, grounded tiers (Clarifying 
   Question -> Conceptual Principle -> Partial Scaffold). Direct solutions are NEVER given.
3. Anti-Cheat Defense Interrogation: Real-time telemetry detects rapid pastes, tab switches, 
   and window unfocus events, locking submissions into "DEFENSE REQUIRED" mode where students 
   must explain execution mechanics.
4. Independent Transfer Verification: Authentic mastery is proven on a related problem with 
   all AI capabilities disabled.
5. Algorithmic Arena: An interactive graph and puzzle laboratory ("Algorithm Arena") where 
   students solve pathfinding, edge relaxation, and sequencing challenges hands-on.

2. FULL-STACK ARCHITECTURE & TECHNOLOGY MATRIX
================================================================================
Frontend:
- Framework: Next.js 14 (App Router) + React 18 + TypeScript
- Styling: Tailwind CSS (Editorial academic palette with dark teal, emerald & cream)
- Iconography: Lucide React
- Visual Canvas: Interactive custom SVG rendering with dynamic node states, pulsing aura, 
  and weighted edge styling
- State & Telemetry: Custom React hooks for window focus/blur monitoring, dynamic pacing, 
  and Dijkstra graph traversals
- Persistence: LocalStorage for high scores and session state; Fetch API for backend sync

Backend:
- Runtime: Python 3.13 (x64 Windows)
- API Framework: FastAPI with Uvicorn ASGI Server
- Data Validation: Pydantic & Pydantic-Settings
- Database: SQLAlchemy ORM with SQLite (data/thinkforge.db)
- Text Extraction: PyMuPDF (fitz) for page-by-page PDF ingestion
- Embeddings: SentenceTransformers (all-MiniLM-L6-v2, 384-dimensional dense vectors)
- Vector Database: ChromaDB with persistent local storage
- LLM Integration: Google GenAI Python SDK (Gemini) with deterministic pedagogical fallback

4. COMPLETE FEATURE BREAKDOWN
================================================================================
4.1. Attempt-Before-Hint Workspace (AssignmentViewer.tsx & page.tsx)
- Code editor with line numbers (1-7), character counting, and attempt versioning (v1, v2).
- AI Mentor panel is physically locked until the student submits an initial attempt.
- Includes a dedicated reflection input for metacognitive reasoning before final submission.

4.2. Progressive Socratic AI Mentor (SocraticChat.tsx & socratic_mentor.py)
- Level 1 — Clarifying Question: Asks what the student tried and redirects attention.
- Level 2 — Conceptual Hint: Explains underlying principles grounded in course materials.
- Level 3 — Partial Outline: Provides scaffolding while leaving synthesis to the learner.
- Grounded Citations: Renders clickable chips referencing uploaded materials (e.g. "Course Notes - Page 12 >").

4.3. Anti-Cheat Integrity Engine (useFocusMonitor.ts & DefenseBanner.tsx)
- Tracks document visibilitychange, window blur, and focus loss events.
- Penalizes pacing timers by 30 seconds for external window departures.
- Automatically triggers "DEFENSE REQUIRED" interrogation upon suspicious pacing or tab shifts.

4.4. Dynamic Pacing Controller (Timer.tsx)
- Calculates target solution time based on assignment complexity (intermediate = 420s).
- Visual MM:SS countdown with dynamic emerald -> amber -> rose threshold transitions.

4.5. Interactive Concept Knowledge Graph (KnowledgeGraph.tsx)
- Renders visual graph nodes: Base Case, Recursive Sub-problem, Call Stack Unwinding, Edge Cases.
- Nodes transition dynamically from "Pending" to "Defense Required" to "Verified" upon passing defense questions.

4.6. AI-Disabled Independent Transfer Challenge (IndependentChallenge.tsx)
- Presents a related transfer problem (e.g., pure recursive Fibonacci without loops).
- High-visibility "AI Disabled" badge reinforces that no hints or mentor calls exist.
- Evaluated with deterministic rubric criteria to measure true mastery.

4.7. Teacher Dashboard & RAG Course Knowledge (TeacherDashboard.tsx & Backend Services)
- Teachers upload text-based PDFs with real-time indexing status.
- PyMuPDF extracts text page by page; chunking service slices text into 400-word windows.
- SentenceTransformers embeds chunks; ChromaDB indexes vectors for filtered retrieval.

4.8. Independence Profile (IndependenceProfile.tsx)
- Transparent audit trail tracking hint usage, focus violations, and transfer performance.
- Avoids fake vanity metrics; displays raw evidence of student independence.

5. ALGORITHM ARENA 2.0 — ANIMATED GAME SUITE & BENCHMARK LAB
================================================================================
5.1. Overview & Game World Architecture
Algorithm Arena 2.0 upgrades the laboratory into an animated, gamified learning 
universe featuring the friendly PathPup mascot, penguin characters, and real 
interactive algorithm mechanics.
- Primary Tagline: "Think Strategically. Solve Algorithmically."
- Core Games:
  1. Dijkstra's Path Adventure (Graph traversal with directional animated arrows)
  2. Bubble Sort: Penguin Parade (Adjacent swap mechanics & early-exit detection)
  3. Selection Sort: Penguin Champion (Minimum scanner & placement swaps)
  4. Sorting Showdown: Comparison Lab (Synchronized live head-to-head simulations)

5.2. Game One: Dijkstra's Path Adventure
- Directional Animated SVG Arrows:
  * Uses SVG markers and trigonometry offsets (radii ~22px) to point accurately from 
    current to next node along graph edges.
  * Native SVG <animateMotion> renders a glowing luminous particle traveling along 
    each path edge.
  * Destination nodes illuminate and emit starburst sparks upon arrival (SparkEffect.tsx).
- Friendly Dog Mascot Companion (PathPup.tsx):
  * Expressive states: idle, thinking, happy (wagging/bouncing on correct moves), 
    sad (drooping ears and encouragement on mistakes), celebrating (party hat & victory pose).
- Interactive 2-Phase Solving Workflow:
  * Phase 1: Exploration, greedy node activation, and edge relaxation.
  * Phase 2: Shortest path reconstruction with "⚡ Auto-Trace from Table", Undo, and Clear.
  * Incomplete path guard prevents premature submission errors.

5.3. Game Two: Bubble Sort — Penguin Parade (BubbleSortGame.tsx)
- Penguins with heights proportional to array values (e.g., [5, 2, 4, 1, 3]).
- Three Interactive Modes:
  * Mode A: Play the Sort (Student chooses "Swap" vs "Keep Order" with validation).
  * Mode B: Predict the Next Move (Interactive quiz on upcoming comparison/swap pairs).
  * Mode C: Watch and Learn (Playback with Play, Pause, Step Forward/Back, Speed controls).
- Visual sorted suffix lock after each pass.
- Early exit optimization: O(n) best-case termination when a pass makes zero swaps.

5.4. Game Three: Selection Sort — Penguin Champion (SelectionSortGame.tsx)
- Visualizes scanning the unsorted array to find the minimum penguin.
- Highlights candidate minimum penguin in emerald with a "MIN" crown badge.
- Compares candidates in cyan and performs exactly one placement swap per pass.
- Educational explanation of why Selection Sort performs at most n - 1 swaps total.

5.5. Game Four: Sorting Showdown — Comparison Lab (SortingComparison.tsx)
- Synchronized side-by-side simulation running Bubble Sort and Selection Sort on 
  the exact same initial array.
- Live telemetry comparing operation counts, swaps, and passes.
- Algorithmic specification table (Best, Average, Worst time, Auxiliary Space, 
  Stability, Swap behavior).
- Socratic reflection prompt testing student comprehension of swap vs scan mechanics.

5.6. Pure Algorithmic Engine & Visualization Library
- sortingAlgorithms.ts: Pure deterministic trace generators for Bubble & Selection sort.
- PenguinArray.tsx: Inline SVG penguin characters with proportional heights and badges.
- SparkEffect.tsx: Non-blocking SVG/CSS starburst particle emitter.
- PathPup.tsx: Vector character mascot with dynamic speech bubble feedback.

7. DIAGNOSED ISSUES, ROOT CAUSES & RESOLUTIONS
================================================================================
Issue 1: TypeError: Cannot read properties of undefined (reading 'toString')
- Location: frontend/src/components/arena/GraphCanvas.tsx (line 164)
- Root Cause: In AlgorithmArena.tsx, distances was initialized as {} on mount. The resetGame() 
  function ran in useEffect after the first render. On frame 0, distances['A'] was undefined. 
  Additionally, isCandidate was checked without being defined from candidateNodeIds.
- Resolution:
  1. Added getInitialDistances() and getInitialPrevious() to pre-populate distances on frame 0.
  2. In GraphCanvas.tsx: added const isCandidate = candidateNodeIds?.has(node.id) ?? false;
  3. Added null-safe formatting: dist === undefined || dist === null || dist === Infinity ? '∞' : dist.toString();
  4. Added defensive null-guards to DistanceTable.tsx.

Issue 2: TypeScript ES5 Set Iteration Build Failure
- Location: frontend/src/components/arena/AlgorithmArena.tsx & graphAlgorithms.ts
- Error: TS2802: Type 'Set<string>' can only be iterated through when using '--downlevelIteration' flag.
- Resolution:
  1. Updated frontend/tsconfig.json compilerOptions: "target": "es2020", "downlevelIteration": true.
  2. Refactored Set spreads ([...set, item]) to new Set(set).add(item) mutations and unvisited.forEach().
  3. Verified npx tsc --noEmit compiles with 0 errors.

Issue 3: Incomplete Path Submission Confusion
- Problem: User completed all 5 node relaxations, but clicking "Submit Shortest Path" 
  failed with: "Expected: A -> C -> B -> D -> E. You submitted: A. Click Reset to try again."
- Root Cause: Reconstructing the shortest path was Phase 2. The path started with just [A]. 
  Clicking submit prematurely submitted only [A]. The error message told the user to reset.
- Resolution:
  1. Added "⚡ Auto-Trace from Table" button that automatically parses the Predecessor table.
  2. Added interactive sequence badges ([ A ] -> [ C ] -> [ B ] -> [ D ] -> [ E ]) with Undo/Clear.
  3. Added Incomplete Path Guard in handleSubmitPath() that warns and guides rather than failing.
