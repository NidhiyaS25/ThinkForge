1. EXECUTIVE PROJECT OVERVIEW
================================================================================
ThinkForge is an educational technology platform and anti-cheat learning management 
system designed to solve a critical flaw in modern AI education: student dependency 
on instant AI answers.

Unlike typical chatbots that act as answer vending machines, ThinkForge enforces:
1. Attempt-Before-Hint: Students must commit an initial answer before AI guidance is 
   unlocked.
2. Progressive Socratic Fading: AI guidance follows 3 structured levels:
   - Level 1: Clarifying Question
   - Level 2: Conceptual Hint (grounded in course notes)
   - Level 3: Partial Scaffolding Outline (leaving final synthesis to the learner)
3. Socratic Defense Interrogation: If submissions are flagged as suspiciously fast, 
   generic, or interrupted by tab-switches, the UI enters "DEFENSE REQUIRED" mode, 
   requiring the student to explain intermediate execution steps.
4. AI-Disabled Independent Transfer: Authentic mastery is measured through a related 
   transfer problem where all AI assistance is completely locked.

2. REQUIREMENT SPECIFICATIONS & SYSTEM ARCHITECTURE
================================================================================
The project was designed with a decoupled full-stack architecture:

- Frontend: Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS, Lucide Icons, 
  and Framer Motion.
- Backend: Python 3.13, FastAPI REST API, Uvicorn ASGI server, SQLAlchemy ORM, and 
  SQLite embedded database.
- Course Knowledge & RAG Layer: PyMuPDF (fitz) page-by-page PDF extraction, 400-word 
  sliding window chunking, SentenceTransformers (all-MiniLM-L6-v2) local 384-d dense 
  embeddings, ChromaDB persistent vector storage, and Google GenAI SDK (Gemini) with 
  deterministic fallback.
- State & Telemetry: Custom React hooks tracking window focus, blur, and tab switching 
  in real-time.

5. CORE COMPONENT & SERVICE HIGHLIGHTS
================================================================================
5.1. useFocusMonitor.ts (Custom Hook)
- Listens to document visibilitychange, window blur, and focus events.
- Flags violations whenever the student minimizes the window or switches tabs.
- Increments violationCount and emits telemetry to the parent workspace.

5.2. Timer.tsx (Pacing Controller)
- Calculates expected time dynamically based on algorithmic complexity (intermediate = 420s).
- Renders MM:SS countdown with dynamic color state transitions (emerald -> amber -> rose).
- Penalizes timer by 30 seconds for every focus violation.

5.3. SocraticChat.tsx (Socratic Dialogue & Interrogation)
- Renders progressive assistance pills: L1 (Clarifying), L2 (Conceptual), L3 (Outline).
- Shows citation chips: "Course Notes - Page 12 >".
- Switches to Socratic Interrogator when an integrity anomaly is detected, prompting:
  "Defense Required: In your implementation, what exact memory state change occurs 
  when n == 0 is evaluated? Walk through the return sequence from factorial(1) to factorial(n)."

5.4. KnowledgeGraph.tsx (Concept Verification Map)
- Visualizes key concept nodes:
  - Base Case Formulation (Verified)
  - Recursive Sub-problem (Verified)
  - Call Stack Unwinding (Pending Defense -> Defense Required -> Verified)
  - Edge Case Guard Rails (Pending)
- Dynamically flips to "Verified" when the student passes Socratic interrogation.

5.5. AssignmentViewer.tsx & page.tsx
- Rich editor with line numbers, character count, and revision versioning (Attempt v1, v2).
- Enforces initial attempt submission before hints unlock.
- Includes a metacognitive reasoning reflection input.

5.6. IndependentChallenge.tsx
- Presents related transfer challenge ("Pure recursive fibonacci(n) without loops").
- Displays high-visibility "AI Disabled" badge.
- Scores responses deterministically against expected boundary criteria.
